# 💜 K-Verse Hub

K-Verse Hub is a K-Pop themed website where users can explore K-Pop groups, live content, news, and official YouTube content in one place.

## ✨ Features

- 🎵 Explore K-Pop groups
- 📰 Latest K-Pop news
- 🔴 Live content section
- ▶️ Official YouTube content
- 📱 Responsive and user-friendly interface
- 💜 K-Pop inspired design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON

## 📂 Project Structure

K-Verse-Hub/
│
├── index.html
├── groups.html
├── groups.json
├── live.html
├── news.html
├── news.json
├── youtube_official.json
├── script.js
├── style.css
└── README.md

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## 🎯 Purpose

This project was created to practice frontend web development, JavaScript, JSON data handling, and responsive UI design through a K-Pop themed website.
